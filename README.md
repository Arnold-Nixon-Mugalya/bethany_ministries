\# Bethany Ministries Portal



A local web application built to manage portal administration data and content dynamically.



\## Tech Stack \& Local Environment

\* \*\*Backend Language:\*\* PHP

\* \*\*Database Engine:\*\* MySQL / MariaDB (Managed via phpMyAdmin)

\* \*\*Local Server Stack:\*\* XAMPP / Apache



\## Installation \& Local Setup Instructions

1\. Clone this repository into your local server root: `C:\\xampp\\htdocs\\`

2\. Open phpMyAdmin (`http://localhost/phpmyadmin/`) and create a new database named `bethany\_db`.

3\. Import the `bethany\_db.sql` file located in the root folder to construct the application schema.

4\. Configure your system connection flags inside `db.php`.

5\. Launch the platform by visiting: `http://localhost/bethany\_ministries/`
